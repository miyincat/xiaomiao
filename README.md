# 筱喵 · 情感陪伴聊天机器人

一只可爱治愈、带点小傲娇的猫娘，陪你聊聊天。

> 筱喵是 AI，不是真人，也不是心理医生或专业顾问。她只负责倾听和陪伴。

---

## 这是什么

一个**纯前端**的情感陪伴聊天页面。没有人设之外的后端，所有逻辑都在浏览器里跑：

| 模块 | 文件 | 作用 |
|---|---|---|
| 人设引擎 | `js/persona.js` | 完整人设、四模式切换规则、口头禅与动作描写约束 |
| 安全兜底 | `js/crisis.js` | **独立于模型**的危险表述识别 + 危机干预三步法 |
| 记忆系统 | `js/memory.js` | 短期上下文 + 长期事实记忆，支持【重置】 |
| 界面 | `js/ui.js` `styles/` | 治愈风 UI、模式配色、气泡与动效 |
| 入口 | `js/main.js` | 串起以上全部 |

## 本地预览

不需要任何构建步骤，也不需要装依赖：

```bash
node server.js
# 打开 http://127.0.0.1:5599
```

也可以直接双击 `index.html`（部分浏览器会限制 `file://` 下的模块加载，推荐用上面的方式）。

## 开始聊天前

点右上角**齿轮 → 填入你自己的 DeepSeek API Key**。

- Key 只保存在**你自己浏览器的 localStorage** 里
- 不会写进代码、不会提交进仓库、不会发往除模型接口以外的任何地方
- 想彻底清掉，点设置面板最下方的「清空全部记忆与设置」

## 四模式设计

模式判定**放在模型之外**（`classify()`），不依赖模型自觉遵守提示词。

优先级：`危机守护 > 情绪安抚 > 游戏 > 日常`

| 模式 | 触发 | 行为 |
|---|---|---|
| 日常 | 默认 | 软萌、嘴硬傲娇、好奇，可轻微闹小脾气 |
| 游戏 | 命中 CS2 / 三角洲行动 / 暗区突围等关键词 | 狂热观众模式，绝不编造选手与赛事 |
| 情绪安抚 | 命中抑郁、崩溃、撑不住等强烈痛苦表述 | **强制关闭**傲娇与游戏，不嘴硬不抬杠 |
| 危机守护 | 命中自伤、轻生等直接危险表述 | 走硬编码三步法 + 紧急资源卡 |

两条被测试锁死的规则：

- `打CS2输了我不想活了` → **危机**（情绪压过游戏话题）
- `我不会自杀的` → **不是危机**（否定语境不误判）

## 安全设计（请勿削弱）

`js/crisis.js` 是整个项目里最不能出错的一块，它**刻意不经过模型**：

1. 规则命中即接管，不给模型"忘记照做"的机会
2. 三步法文案硬编码：接住情绪 → 确认安全 → 温柔转介
3. 紧急资源卡固定展示 **110 / 120 / 12356**（12356 为国家卫健委全国统一心理援助热线）
4. 危机模式下**禁止**任何傲娇措辞与可爱动作描写

改动这一层后，请务必跑一遍自测：

```bash
node _test/crisis.test.mjs
```

33 条断言覆盖一级危险、二级痛苦、否定语境、日常放行、模式优先级。

## 部署到 GitHub Pages

仓库已带好工作流 `.github/workflows/pages.yml`，推送后自动发布。

1. 在 GitHub 新建仓库并推送（见下方命令）
2. 仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**
3. 等待 Actions 跑完，访问 `https://<你的用户名>.github.io/<仓库名>/`

```bash
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git branch -M main
git push -u origin main
```

## 已知限制（重要）

这台项目是**纯前端**，有些事它做不到，写在这里避免误解：

- **API Key 要每个访问者自己填。** 因为仓库是公开的，把 Key 写进代码等于公开发放。如果要做成"访问者不用填 Key"的公共服务，必须加后端（Cloudflare Workers / Vercel 等），由后端持有 Key 并转发请求。
- **可能有跨域限制。** 浏览器直连模型接口是否成功，取决于对方是否放行 CORS。若被拦下，页面会明确提示，可在设置里把「接口地址」换成自建代理。
- **记忆只在本机。** 长期记忆存在 localStorage，换设备或换浏览器就没了。
- **CS2 知识库尚未接入。** 目前靠"不知道就说不知道"兜底，**绝不编造**选手与赛事信息。真实数据源需要后端支持。
- **不要用这个页面替代真实的危机干预。** 它只是一个缓冲垫，真正的帮助来自专业人员和身边的人。
